# Efficient Document Forgery Detection Using Lightweight Vision Transformers and Explainable AI

This repository contains the source code, model architectures, evaluation benchmarks, and publication figures for Document Forgery Detection.

Pretrained checkpoints for all 5 models (MobileViT-v2 1.0 E5-B, ShuffleNetV2, EfficientNet-B0, MobileNetV3-Large, and ViT-Tiny) are available in the **[Releases](../../releases)** section.
